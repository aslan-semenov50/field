# FIELD

FIELD — UI-прототип сервиса для осмысленного поиска работы и карьерного роста. Проект показывает, как можно объединить резюме, отклики, аналитики и состояние активности по площадкам в одном интерфейсе.

## Текущий статус

UI Prototype

## Стек

- React 18
- TypeScript
- Vite
- lucide-react

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```
